# 198. House Robber

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/house-robber/

## Способ решения

На каждом шаге принимается решение: взять текущий дом или пропустить его. Если беру текущий — прибавляю его деньги к лучшему результату за два дома до него (prev2). Если пропускаю — беру лучший результат за один дом до него (prev1). Храню только два предыдущих значения, чтобы не использовать лишнюю память. Инициализирую prev2 = nums[0] и prev1 = max(nums[0], nums[1]) и начинаю проход с третьего элемента (индекс 2).

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(1) — только две переменные
