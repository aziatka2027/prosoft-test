# 56. Merge Intervals

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/merge-intervals/

## Идея решения

Сначала сортирую интервалы по началу. После сортировки пересекаться могут только соседние интервалы. Затем прохожу по отсортированному списку и объединяю те интервалы, которые пересекаются с последним добавленным в результат.

## Сложность

- **Время:** O(n log n) — из-за сортировки
- **Память:** O(n) — для хранения результата

## Как работает код

1. Сортирую `intervals` по началу.
2. Создаю пустой вектор `result`.
3. Прохожу по всем интервалам:
   - Если `result` пуст или текущий интервал не пересекается с последним в `result` (его начало больше конца последнего) — добавляю его как новый.
   - Иначе — расширяю конец последнего до максимума из двух концов.
4. Возвращаю `result`.
