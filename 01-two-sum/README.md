# 1. Two Sum

**Сложность:** Easy

**Ссылка на LeetCode:** https://leetcode.com/problems/two-sum/

## Способ решения

Использую `unordered_map` для хранения чисел и их индексов. Прохожу по массиву один раз: для каждого числа вычисляю второе слагаемое (`target - nums[i]`) и проверяю, есть ли оно уже в словаре. Если есть — возвращаю его индекс и текущий. Если нет, добавляю текущий индекс со значением в словарь.

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(n) — словарь может содержать до n элементов
