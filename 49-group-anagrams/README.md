# 49. Group Anagrams

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/group-anagrams/

## Способ решения

Анаграммы — это слова, состоящие из одних и тех же букв. Если отсортировать буквы в каждом слове, все анаграммы дадут одинаковую строку. Использую эту отсортированную строку как ключ в `unordered_map`, а значением будет список оригинальных слов. Выбор `unordered_map` обусловлен максимальной скоростью поиска ключа.

## Сложность

- **Время:** O(n · k log k) — где n — количество слов, k — длина самого длинного слова (сортировка каждого слова занимает O(k log k))
- **Память:** O(n · k) — для хранения всех слов в словаре
