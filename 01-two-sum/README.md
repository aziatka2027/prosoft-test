# 1. Two Sum

**Сложность:** Easy

**Ссылка на LeetCode:** https://leetcode.com/problems/two-sum/

## Способ решения

Использую `unordered_map` для хранения чисел и их индексов. Прохожу по массиву один раз: для каждого числа вычисляю второе слагаемое (`target - nums[i]`) и проверяю, есть ли оно уже в словаре. Если есть — возвращаю его индекс и текущий. Если нет — добавляю текущее число и его индекс в словарь.

## Сложность

- **Время:** один проход по массиву, при среднем O(1) для операций unordered_map.
- **Память:** O(n) — словарь может содержать до n элементов
