# 14. Longest Common Prefix

**Сложность:** Easy

**Ссылка на LeetCode:** https://leetcode.com/problems/longest-common-prefix/

## Способ решения

Используя вложенный цикл (For) беру первый символ первой строки и проверяю, есть ли он на той же позиции во всех остальных строках. Если да — добавляю его к префиксу и перехожу к следующему символу первой строки. Если нет — возвращаю накопленный префикс.

## Сложность

- **Время:** O(n · m) — где n — количество строк, m — длина самой короткой строки (в худшем случае)
- **Память:** O(1) — не считая памяти под результат
