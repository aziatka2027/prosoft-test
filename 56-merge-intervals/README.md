# 56. Merge Intervals

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/merge-intervals/

## Способ решения

Сначала сортирую интервалы по началу стандартным методом sort. После сортировки пересекаться могут только соседние интервалы. Создаю пустой вектор `result`
Затем прохожу по отсортированному списку и объединяю те интервалы, которые пересекаются с последним добавленным в результат. Если текущий интервал не пересекается с последним в `result` (его начало больше конца последнего) — добавляю его как новый.

## Сложность

- **Время:** O(n log n) — из-за сортировки
- **Память:** O(n) — для хранения результата
