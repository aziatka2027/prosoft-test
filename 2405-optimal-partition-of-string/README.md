# 2405. Optimal Partition of String

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/optimal-partition-of-string/

## Способ решения

Использую счетчик count для подсчета количества подстрок с уникальными символами и множество unordered_set<char> (temp) для временного сбора символов, т.к. этот тип контейнера позволяет производить поиск с максимальной эффективностью. Иду по строке и собираю символы в temp. Как только встречаю символ, который уже есть в множестве, это значит, что текущая подстрока закончилась — начинаю новую и увеличиваю счетчик.

## Сложность

- **Время:** O(n) — один проход по строке
- **Память:** O(k) — где k в данном случае ограничен размером алфавита, т.к. по условию s состоит только из строчных букв английского алфавита
