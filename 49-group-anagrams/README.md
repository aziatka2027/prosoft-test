# 49. Group Anagrams

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/group-anagrams/

## Идея решения

Анаграммы — это слова, состоящие из одних и тех же букв. Если отсортировать буквы в каждом слове, все анаграммы дадут одинаковую строку. Использую эту отсортированную строку как ключ в `unordered_map`, а значением будет список оригинальных слов.

## Сложность

- **Время:** O(n · k log k) — где n — количество слов, k — длина самого длинного слова (сортировка каждого слова занимает O(k log k))
- **Память:** O(n · k) — для хранения всех слов в словаре

## Как работает код

1. Создаю `unordered_map<string, vector<string>> groups`.
2. Прохожу по всем словам:
   - Копирую слово в `key` и сортирую буквы.
   - Добавляю оригинальное слово в группу `groups[key]`.
3. Собираю все группы в итоговый вектор `result`.
4. Возвращаю `result`.
