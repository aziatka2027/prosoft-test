# 14. Longest Common Prefix

**Сложность:** Easy

**Ссылка на LeetCode:** https://leetcode.com/problems/longest-common-prefix/

## Идея решения

Использую метод вертикального сканирования: беру первый символ первой строки и проверяю, есть ли он на той же позиции во всех остальных строках. Если да — добавляю его к префиксу и перехожу к следующему символу. Если нет — возвращаю накопленный префикс.

## Сложность

- **Время:** O(n · m) — где n — количество строк, m — длина самой короткой строки (в худшем случае)
- **Память:** O(1) — не считая памяти под результат

## Как работает код

1. Если вектор пуст — возвращаю пустую строку.
2. Если в векторе одна строка — возвращаю её.
3. Иду по символам первой строки:
   - Для каждого символа проверяю все остальные строки.
   - Если строка короче или символ не совпадает — возвращаю накопленный префикс.
   - Если все строки прошли проверку — добавляю символ к префиксу.
4. Возвращаю префикс.
