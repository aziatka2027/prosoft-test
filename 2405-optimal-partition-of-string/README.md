# 2405. Optimal Partition of String

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/optimal-partition-of-string/

## Идея решения

Использую жадный алгоритм с `unordered_set`. Иду по строке и собираю символы в текущую подстроку. Как только встречаю символ, который уже есть в множестве, это значит, что текущая подстрока закончилась — начинаю новую. Считаю количество таких подстрок.

## Сложность

- **Время:** O(n) — один проход по строке
- **Память:** O(k) — где k — размер алфавита (для строчных букв это константа)

## Как работает код

1. Создаю `unordered_set<char> temp` для символов текущей подстроки.
2. Счётчик `count = 1`.
3. Прохожу по символам строки:
   - Если символ уже есть в `temp` — увеличиваю `count` и очищаю множество.
   - Добавляю символ в `temp`.
4. Возвращаю `count`.
