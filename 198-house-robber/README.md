# 198. House Robber

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/house-robber/

## Идея решения

На каждом шаге принимается решение: взять текущий дом или пропустить его. Если беру текущий — прибавляю его деньги к лучшему результату за два дома до него. Если пропускаю — беру лучший результат за один дом до него. Храню только два предыдущих значения, чтобы не использовать лишнюю память. prew1 - лучший результат предыдущего дома, prew2 - лучший результат для позапрошлого дома. Первоначально инициализируем `prev2 = nums[0]` и `prev1 = max(nums[0], nums[1])` и начинаем проход по массиву с 3-го дома

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(1) — только две переменные
