# 11. Container With Most Water

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/container-with-most-water/

## Идея решения

Использую метод двух указателей: один ставится в начало массива, второй — в конец. На каждом шаге вычисляю площадь между ними и запоминаю максимум. Затем сдвигаю тот указатель, который указывает на меньшую высоту — потому что именно низкая стенка ограничивает площадь, и сдвиг высокой ничего не улучшит.

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(1) — только несколько переменных

## Как работает код

1. Ставлю `left = 0`, `right = height.size() - 1`.
2. Пока `left < right`:
   - Вычисляю ширину: `width = right - left`.
   - Вычисляю высоту: `h = min(height[left], height[right])`.
   - Считаю площадь: `area = width * h`.
   - Обновляю максимум: `maxarea = max(maxarea, area)`.
   - Сдвигаю указатель с меньшей высотой.
3. Возвращаю `maxarea`.
