# 198. House Robber

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/house-robber/

## Идея решения

Использую динамическое программирование. На каждом шаге решаю: ограбить текущий дом или пропустить его. Если граблю — прибавляю его деньги к лучшему результату за два дома до него. Если пропускаю — беру лучший результат за один дом до него. Храню только два предыдущих значения, чтобы не использовать лишнюю память.

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(1) — только две переменные

## Как работает код

1. Если массив пуст — возвращаю 0.
2. Если один дом — возвращаю его.
3. Инициализирую `prev2 = nums[0]` и `prev1 = max(nums[0], nums[1])`.
4. Прохожу с третьего дома:
   - `current = max(prev1, prev2 + nums[i])`.
   - Сдвигаю окно: `prev2 = prev1`, `prev1 = current`.
5. Возвращаю `prev1`.
