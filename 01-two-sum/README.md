# 1. Two Sum

**Сложность:** Easy

**Ссылка на LeetCode:** https://leetcode.com/problems/two-sum/

## Идея решения

Использую `unordered_map` для хранения чисел и их индексов. Прохожу по массиву один раз: для каждого числа вычисляю второе слагаемое (`target - nums[i]`) и проверяю, есть ли оно уже в словаре. Если есть — возвращаю его индекс и текущий.

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(n) — словарь может содержать до n элементов

## Как работает код

1. Создаю `unordered_map<int, int>` для хранения чисел и их индексов.
2. Прохожу по массиву:
   - Вычисляю `add = target - nums[i]`.
   - Если `add` уже есть в словаре — возвращаю `{ mp[add], i }`.
   - Иначе добавляю текущее число и его индекс в словарь.
3. Если решение не найдено — возвращаю пустой вектор.
