# 198. House Robber

**Сложность:** Medium

**Ссылка на LeetCode:** https://leetcode.com/problems/house-robber/

## Идея решения

На каждом шаге принимается решение: взять текущий дом или пропустить его. Если беру текущий — прибавляю его деньги к лучшему результату за два дома до него (pref2). Если пропускаю — беру лучший результат за один дом до него (pref1). Храню только два предыдущих значения, чтобы не использовать лишнюю память. Первоначально инициализирую `prev2 = nums[0]` и `prev1 = max(nums[0], nums[1])` и начинаю проход по массиву с 3-го дома

## Сложность

- **Время:** O(n) — один проход по массиву
- **Память:** O(1) — только две переменные
